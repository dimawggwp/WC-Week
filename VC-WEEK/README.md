# Polus Bank — прототип крипто-необанка

Интерактивный mobile-first прототип. Чистые HTML, CSS и JS: без бэкенда, без базы данных, без сборки.

- **Курсы реальные:** криптовалюты берутся из CoinGecko (публичный API без ключа), USD/KZT, EUR, RUB, CNY из ExchangeRate-API. Обновление раз в минуту. GOLD = цена PAXG за тройскую унцию / 31,1035 (цена 1 грамма золота).
- **Без интернета** показываются последние сохранённые котировки, приложение не ломается.
- **Балансы, сделки и пользователи тестовые.** Логотипы монет лежат локально в `assets/coins/`.

## Запуск локально
```bash
cd ~/Desktop/VC-WEEK
python3 -m http.server 8000
# открыть http://localhost:8000
```

## GitHub Pages
Загрузите в репозиторий файлы `index.html`, `styles.css`, `app.js` и папку `assets/` (вместе с `assets/coins/`), затем включите Pages (Settings → Pages → Deploy from branch → main / root).

## Тестовые данные
- Вход: **клиент** или **продавец**, у каждого «Войти» или «Регистрация»
- SMS-код: **1234** (любой другой код покажет ошибку)
- PIN: любые 4 цифры или Face ID; **0000** = ошибка
- Сбросить демо: Профиль → «Сбросить демо»

Состояние хранится в localStorage браузера. Сценарий защиты описан в `PITCH.md`.
